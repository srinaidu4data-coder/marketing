# Psychologically Superior Resume Structure (Role Forge)

**Purpose:** Replace the classic 5-block outline with a structure grounded in psychological science (last ~100 years; emphasis last ~25 years) for **human recruiters + ATS**, while remaining factual to the master resume.

**Status:** Design standard for progressive tailor / admin prompt middle section.

---

## 1. Research synthesis (what science says)

### A. Attention & scanning (eye-tracking / UX psych)
- Recruiters do **not** read linearly; they **F-pattern / skim** headlines, left edge, and early bullets (Nielsen-style web reading; recruiting studies show 6–30 second initial pass).
- **Implication:** Put high-signal, JD-matched content in the first screen: title, 3–4 summary lines, skills, **first two roles**.

### B. Dual-process judgment (Kahneman System 1 / System 2)
- System 1 forms a **thin-slice first impression** (Ambady thin-slicing tradition); System 2 verifies consistency.
- **Implication:** Instant “fit” via title + summary + skills; then detailed bullets must not contradict the first impression (reduces cognitive dissonance).

### C. Processing fluency (Schwarz et al.; Reber & Schwarz)
- Easy-to-process text is judged more **true, competent, and trustworthy**.
- **Implication:** Clean title (not descriptive sentence), consistent acronyms, short scannable bullets, modern but readable jargon (not wall-of-text).

### D. Schema matching & category accessibility (Bartlett; modern person-perception)
- Decision makers match candidates to a **job schema**. Overlap with JD terms increases “feels right” fit (similarity-attraction / encoding specificity).
- **Implication:** Mirror JD terminology and acronym style exactly in title, summary, stack, and top bullets.

### E. Primacy + recency (Ebbinghaus / serial position)
- First and last items in a list are remembered better.
- **Implication:** Strongest JD-aligned bullets first **and** last in each role; strongest roles first (recent).

### F. Peak–end rule (Kahneman)
- Evaluation is driven by peaks and the ending, not the average.
- **Implication:** At least one quantified “peak” win per recent role; end each role with impact/result bullet; end resume with education/cert or clear availability signal if needed.

### G. Construal level / abstraction (Trope & Liberman, last ~25 yrs)
- Distant future/high-level = abstract (“strategic transformation”); near = concrete (“configured ATTP rule sets”).
- **Implication:** Summary = high-level fit + technical jargon; bullets = concrete actions + tools + outcomes.

### H. Narrative identity & progressive self (McAdams; last 25 yrs narrative psych)
- People prefer coherent **growth stories** over random achievement lists.
- **Implication:** Career arc visible: early foundation → mid ownership → recent leadership (without inventing facts).

### I. Cognitive load & chunking (Miller; modern CLT Sweller)
- Working memory is limited; chunked sections reduce load.
- **Implication:** Separate **Skills** vs **Stack per role**; avoid dumping JD noise (Location, Remote, Interview Mode).

### J. Signaling theory (Spence) & modern hiring psych
- Credentials and specificity signal competence; vague claims signal fluff.
- **Implication:** Prefer quantified outcomes, named modules (GS1, EPCIS, GTIN), named processes over empty adjectives.

### K. Last ~25 years extras
- **Implementation intentions / goal framing** (Gollwitzer): bullets as “if/when–then” delivery language (“When UAT blocked, triaged defects…”).
- **Regulatory focus** (Higgins): promotion language for growth roles; prevention language for compliance/pharma (ATTP/DSCSA).
- **Authenticity / overclaim detection** (social psych of resume fraud): temporal integrity and progressive balance reduce “too good” rejection.

## 2. Greater structure (recommended) — 9-block model

> **Order is intentional:** System-1 fit → schema match → proof → peaks → arc → close.

### BLOCK 0 — IDENTITY STRIP (not a section title)
**Psych:** Fluency + category labeling (job schema activation).  
**Rules:**
- **Name** (as on master / brand)
- **Resume Title / Headline = Job Title only** (from JD)
  - Title-like: `SAP ATTP Functional Consultant`
  - **Not** descriptive: ~~“Experienced consultant specializing in…”~~
  - Match JD acronym style, version notation, word order exactly
- **Contact line** (email; optional phone/location only if on master)

### BLOCK 1 — PROFESSIONAL SUMMARY (6–8 sentences)
**Psych:** System-1 fit + fluency + high-level construal + keyword encoding.  
**Rules:**
- Rewrite from scratch as **near-total JD match**
- Modern technical jargon (domain-correct: ATTP/serialization ≠ FICO fluff)
- Mirror JD terminology and pack **JD keywords**
- Sentences 1–2: identity + years + core domain match  
- Sentences 3–5: technical depth + IT jargon aligned to JD  
- Sentences 6–8: delivery model (programs, stakeholders, compliance/transformation) + progressive arc teaser  
- **No** job-board noise (remote, foster city, interview mode)

### BLOCK 2 — CORE COMPETENCIES / TECHNICAL SKILLS
**Psych:** Chunking + schema checklist match (recruiter “scan for keywords”).  
**Rules:**
- Reorder to **lead with JD skills**
- Prefer master-supported skills; add JD skills only when temporally/domain-honest
- Group: **Core | Platforms & Integration | Methods** (3 lines max)
- Dense, scannable separators (·)

### BLOCK 3 — SELECTED IMPACT SNAPSHOT (optional but high power) — 3–5 bullets
**Psych:** Peak–end + System-1 proof before deep read; reduces bounce.  
**Rules:**
- Only from recent/mid master facts or domain-honest delivery outcomes
- Prefer quantified outcomes
- Place **before** full experience so skimmers get proof early

### BLOCK 4 — PROFESSIONAL EXPERIENCE (roles reverse-chronological)
**Psych:** Primacy of recent roles; narrative progressive arc.

#### 4A. Project / Role Header
**Psych:** Category label for each engagement + tool schema match.  
**Rules:**
- Line 1: **Title — Client/Program** (title aligned to career stage + JD domain)
- Line 2: Location | dates (muted)
- Line 3: **Stack / Modules / Environment**  
  - Must cover JD tools/tech for **recent** roles  
  - Mid/early: only era-appropriate stack (temporal integrity)

#### 4B. Experience bullets (ONE LAW: 8–12 per employer, all eras; preferred 10)
**Psych:** Concrete construal + primacy/recency within role + regulatory focus for compliance domains.  
**Structure each bullet as:**  
`Action verb + JD-aligned work + tool/module + (optional metric/outcome)`  
**Rules:**
- Rewrite from master facts; do not invent employers/dates
- Front-load JD-aligned work
- Prefer quantified outcomes when available
- Recent roles: aggressive JD keyword weave  
- Early roles: balanced, progressive, no oversell
- First bullet = strongest fit; last bullet = peak outcome or KT/hypercare close

### BLOCK 5 — CROSS-ENGAGEMENT HIGHLIGHTS (short)
**Psych:** Narrative coherence + multi-peak aggregation.  
**Rules:** 4–6 lines tying multi-project story to JD themes (e.g. serialization, transformation programs).

### BLOCK 6 — METHODS / HOW I DELIVER (short)
**Psych:** Implementation-intention language; process trust for enterprise buyers.  
**Rules:** Workshop → design → build → test → cutover → hypercare (domain-flavored).

### BLOCK 7 — EDUCATION & CREDENTIALS
**Psych:** Signaling; close the document with stability cues.

### BLOCK 8 — FOOTER (export chrome only)
**Psych:** Minimal; avoid ATS noise. Layout name only; no internal debug labels.

## 4. Domain example (ATTP JD)

- **Title:** `SAP ATTP Functional Consultant` (not a paragraph)  
- **Summary:** ATTP, serialization, GS1/GTIN/GLN/SSCC, EPCIS, pharma packaging/aggregation, EDI/ALE, transformation programs  
- **Stack (recent):** SAP ATTP · GS1 · EPCIS · GTIN/GLN/SSCC · EDI/ALE · Packaging/Aggregation · Track & Trace  
- **Bullets:** functional workstream leadership, rule/config, exception handling, SIT/UAT, cutover, compliance evidence  
- **Early career:** foundation SAP + supply chain/compliance exposure without claiming ATTP lead ownership if era-invalid

## 5. Non-negotiable integrity constraints

1. No invented employers, dates, or certifications  
2. Temporal skill integrity (no S/4/ATTP on impossible eras)  
3. Progressive balance (don’t oversell early)  
4. Never dump JD noise fields into skills  
5. Internal ATS target ≥ 95 after reinforcement
